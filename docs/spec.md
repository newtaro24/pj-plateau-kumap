# 機能仕様書

**最終更新**: 2025-11-12
**ステータス**: 草案（PLATEAUデータを触りながら詳細化予定）

## プロジェクト概要

札幌市民（特に山林近郊の住民）のための、実践的なヒグマ危険度3Dマップ&シミュレーターアプリ

## コアコンセプト

**「不意のヒグマとの遭遇に怯えている人の助けになる」**

## ターゲットユーザー

1. 札幌市民（特に山林近郊の住民）
2. 登山・ハイキング愛好家
3. 学校・保育施設の関係者
4. 地域の防災担当者

## 想定機能（優先度順）

### MVP（Minimum Viable Product）

#### 1. 3D地図の基本表示 ⭐⭐⭐
- 札幌市の3D都市モデル表示
- 基本的なナビゲーション（ズーム、回転、移動）
- 山林エリアの識別

#### 2. ヒグマ目撃情報の可視化 ⭐⭐⭐
- 目撃地点のマーカー表示
- 目撃日時の表示
- 目撃情報の詳細（クリックで表示）

#### 3. 時系列フィルタリング ⭐⭐
- 期間指定での絞り込み
- 「過去1週間」「過去1ヶ月」などのクイックフィルタ

### 拡張機能（検討中）

#### 4. 危険度ヒートマップ ⭐⭐
- 目撃頻度に基づく危険度の可視化
- 色分け表示（緑→黄→赤）

#### 5. 出没傾向分析 ⭐
- 時期による出没パターン
- 時間帯による傾向
- グラフ表示

#### 6. 経路シミュレーション ⭐
- ユーザーが指定した経路の危険度評価
- より安全な代替ルート提案

#### 7. リアルタイム警戒情報
- 最新の目撃情報のプッシュ通知（要検討）
- 危険度アラート

## 非機能要件

- **パフォーマンス**: 3秒以内の初期ロード
- **ブラウザ対応**: Chrome, Firefox, Safari, Edge（最新版）
- **レスポンシブ**: デスクトップ優先、モバイルは将来対応
- **アクセシビリティ**: 基本的なキーボード操作対応

## データ仕様

### 入力データ

1. **PLATEAU 3D都市モデル**
   - フォーマット: CityGML → 3D Tiles
   - 対象: 札幌市全域

2. **ヒグマ出没情報**
   - フォーマット: GeoJSON
   - 必須フィールド: 緯度、経度、日時
   - オプション: 詳細情報、出没状況

### データ更新頻度

- 3D都市モデル: 静的（年次更新レベル）
- ヒグマ情報: 動的（理想は日次、現実的には手動更新）

## UI/UX方針

- シンプルで直感的な操作
- 3D地図をメインに配置
- サイドパネルでフィルタ・詳細情報表示
- カラーは危険度を直感的に理解できる配色
