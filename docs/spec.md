# 機能仕様

## コンセプト

**「ヒグマに遭ったら、あなたは生き残れるか？」**

PLATEAUの3D建物データを活用し、ヒグマ遭遇時の「逃げ場があるか」を可視化する。

## コア機能

### 1. 避難場所スコア（最優先）

出没地点から最寄りの建物までの距離を計算・表示。

| 項目 | 内容 |
|------|------|
| 距離計算 | 出没地点→最寄り建物の距離 |
| 表示 | マーカークリック時に「○○m」表示 |
| 色分け | 遠い=赤、近い=緑 |

### 2. 建物密度の可視化

エリアごとの建物密度をヒートマップで表示。

| 項目 | 内容 |
|------|------|
| 集計 | グリッドごとの建物数 |
| 表示 | 密度ヒートマップ |
| 意味 | 建物が疎なエリア=危険 |

## 技術的課題

- Cesium 3D Tilesから建物座標を取得する方法
- 点と建物の距離計算
- パフォーマンスを考慮した空間検索
