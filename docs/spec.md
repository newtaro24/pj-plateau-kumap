# 機能仕様書

**最終更新**: 2025-11-17
**ステータス**: Phase 3準備中（データビジュアライゼーション路線へ転換）

## プロジェクト概要

札幌ヒグマ出没3Dビジュアライザー - PLATEAUとヒグマデータを組み合わせたインタラクティブなデータビジュアライゼーション作品

## コアコンセプト

**「データで見える、ヒグマと都市の距離」**

- 見て面白い、触って楽しいデータ体験
- 技術デモとしての完成度重視
- 結果的に防災意識向上にも貢献

## ターゲット層

1. **メイン**: データビジュアライゼーションに興味がある層
2. **サブ**: 札幌市民・防災関係者（実用的な価値も提供）
3. **アーバンデータチャレンジ審査員**（PLATEAUの新しい活用例として）

## データ仕様

### 入力データ

1. **PLATEAU 3D都市モデル**
   - フォーマット: CityGML → 3D Tiles
   - 対象: 札幌市全域

2. **ヒグマ出没情報**
   - フォーマット: GeoJSON
   - 必須フィールド: 緯度、経度、日時
   - オプション: 詳細情報、出没状況

### データ更新頻度

- 3D都市モデル: 静的（年次更新レベル）
- ヒグマ情報: 動的（理想は日次、現実的には手動更新）

## UI/UX方針

### デザインコンセプト
- **見やすさ優先**: 3D地図を最大限に表示
- **インタラクティブ**: 触って楽しい操作感
- **没入感**: UIは最小限、データに集中できる

### レイアウト
- **メインエリア**: Cesium 3Dビューワー（全画面）
- **コントロールパネル**: 左下または右下にオーバーレイ
  - 時系列コントロール（再生/一時停止/スライダー）
  - ヒートマップON/OFF
  - カメラツアー開始
- **情報パネル**: 右上に統計情報（必要時のみ表示）
- **クレジット**: 右下（現状維持）

### カラースキーム
- **背景**: ダーク系（3Dモデルを引き立てる）
- **マーカー**: 赤（高危険）/ 黄（中危険）/ 緑（低危険）
- **ヒートマップ**: 青→緑→黄→赤のグラデーション
- **UI**: シンプルな白または薄いグレー
