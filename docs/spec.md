# 機能仕様

## コンセプト

**札幌市ヒグマ出没マップ**

PLATEAUの3D都市モデルを活用し、ヒグマ出没データを空間的に可視化する。
目撃時の状況（時刻・場所・種別）をリアルに体験できるビューアを目指す。

---

## 現在の機能（実装済み）

### 1. 統計ダッシュボード
- 月別・区別・時間帯別・曜日別の出没統計
- 状況タイプ別（目撃/足跡/フン等）の集計
- フィルタリング機能（月・区で絞り込み）

### 2. 3Dマップ表示
- PLATEAU 3D都市モデル（札幌市全10区対応）
- ヒグマ出没地点マーカー
- 白地図ベースマップ + 地形データ
- ズームイン/アウトコントロール

### 3. 出没情報パネル
- マーカークリックで詳細表示
- 日時・場所・状況・区の情報

### 4. 日照シミュレーション
- 太陽ボタン（☀）で照明のオン/オフ
- マーカー選択中は目撃日時の太陽位置・影を再現
- Cesium enableLighting使用

## 技術メモ

### 日照シミュレーション実装方法
```typescript
// 照明を有効化
viewer.scene.globe.enableLighting = true;

// 目撃日時を設定
viewer.clock.currentTime = JulianDate.fromIso8601('2025-04-03T09:30:00+09:00');
viewer.clock.shouldAnimate = false;
```

### 状況タイプ（situation）の種類
- ヒグマを目撃
- ヒグマらしき動物を目撃
- ヒグマを目撃（親子）
- 足跡を確認
- フンを確認
- 足跡・フンを確認
- カメラでヒグマを確認
- カメラでヒグマを確認(親子)
- ヒグマを駆除
