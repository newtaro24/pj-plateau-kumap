以下のルールに従ってgitコミットを作成してください：

1. `git status` と `git diff` で変更内容を確認
2. `git add` で関連ファイルを追加
3. **短い英語のコミットメッセージ**を書く（命令形、50文字以内）
4. **小さく集中したコミット**を作る（単一の論理的な変更）
5. **Co-Authored-By フッターは追加しない**
6. **絵文字や "Generated with Claude Code" メッセージは追加しない**
7. シンプルに `git commit -m "message"` 形式を使う

良いメッセージの例:
- "Add initial documentation"
- "Setup project structure"
- "Configure Cesium JS"
- "Fix marker positioning"

コミット後、`git status` で確認すること。
