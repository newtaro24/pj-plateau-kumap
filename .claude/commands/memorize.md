- **名前**: pj-plateau-kumap

## 技術スタック
- **フロントエンド**: TypeScript + React + Vite
- **3D可視化**: Cesium JS + Resium
- **理由**: Vite選択（Next.jsより高速HMR、SSR不要、Cesiumとの相性良好）
